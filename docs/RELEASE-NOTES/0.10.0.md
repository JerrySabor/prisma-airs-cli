M6e Gateway: airs-cli-rs now covers the TypeScript CLI's AI Gateway commands, under the new name
`gateway`. It has every read, write, inference call and the HTML report, plus a `Gateway API`
check in `doctor`. 0.10 also carries 0.9.1's move to scm-sdk 0.2.2, now with the SDK's `gateway`
feature.

## Install or upgrade

```sh
cargo install --locked airs-cli     # or download a tarball below
airs-cli-rs --version               # 0.10.0
```

No store changes since 0.3. Tenants imported with `tenant import` keep working, and their `aiGw*`
keys were renamed `gateway*` in 0.3. `doctor` uses the tenant's `gatewayDataEndpoint` and
`gatewayAdminEndpoint`.

## New commands

All under `gateway` (TypeScript `aigateway`; there is no `aigateway` alias, D227):

- **Workspaces and scopes:**
  - `workspaces list`, `get`, `create`, `update`, `archive`
  - `scopes list`, `get`, `create`, `bind`, `delete`
- **Telemetry:** `cost`, `cache summary`, `cache trend`, `error-category-trends`, `error-trends`,
  `errors`, `feedback distribution`, `feedback models`, `feedback trend`, `feedback weighted`,
  `filter-boundaries`, `group-by`, `grouped-errors`, `latency`, `logs list`, `requests`,
  `rescued-retries`, `tokens`, `user-trends`, `users`
- **Inventory**, with its creates, updates, deletes, rotations, syncs and upserts:
  - `api-keys service` and `api-keys user`
  - `audit-logs list`
  - `configs`, including `versions`
  - `deployments`, including `ping`
  - `guardrails`, including `catalog`
  - `integrations`, including `providers`, `models list` and `workspaces`
  - `mcp integrations`, including `capabilities`, `metadata` and `workspaces`
  - `organisations` (`info`, `self`, `auth-settings`)
  - `plugins`
  - `providers`
  - `admin-guardrails`, including `mcp-servers`
- **Inference:** `inference chat`, `responses`, `embeddings`, with `--stream`
- **Report:** `report` (alias `dashboard`), the HTML gateway report
- **Doctor:** the `Gateway API` check (D250)

## Safety

- **Credentials never reach the terminal.**
  - One-time credentials go only to a required, new 0600 `--secret-output` file. They come from
    API-key create and rotate, deployment create and `--rotate-auth`. `--show-secret` is refused
    (D237).
  - Every gateway read and write answer withholds credentials in every format as `[withheld]`.
    That covers provider keys and configurations, integration and MCP secrets, SSO/SCIM secrets,
    credentials stored as JSON text, and URL userinfo and queries (D238, D251).
  - Audit-log request bodies, headers and queries are withheld by default (D239).
    `--reveal-sensitive` shows them with credentials still withheld.
- **Inference uses only the tenant's credentials.** It never reads `PANW_AI_GW_INFERENCE_*`
  environment variables (D240). Model text is printed through the terminal-safe filter. An
  interrupted call exits 130 or 143 (D241).
- **Every write is sent once.** A 401 is replayed once and a 403 never; TypeScript re-sends up to
  5 times. When the outcome is unknown, the CLI says so (D228).
- **Workspace resolution fails closed.** A failed list is an error and an unmatched name is
  refused. Over an incomplete list, only an exact id or slug resolves (D235, D254).
- **Confirmations** follow D81 for deletes, archives, rotations and replacing or tenant-wide
  writes. Without a terminal, `--force` is required (D243).
- **Checks come first.** Argument checks are usage errors before the tenant is read (D232).
  `--file` is a bounded JSON object (D246). Credential inputs are checked before any request, and
  `--key-stdin` must be piped (D247).
- **Times are explicit.** Telemetry and report windows take zoned ISO times and are sent in UTC,
  whatever the host's zone (D242, D249).

## Other differences from the TypeScript CLI (DESIGN §12)

one report renderer.

## Verified

- The full loopback and parity suite passes (3,303 tests).
- Against a real tenant (2026-10-19), every live tier agrees with the TypeScript CLI:
  - the base comparison: 20 checks, with all 8 scans;
  - the red team reads: 19;
  - the DLP reads: 13;
  - the runtime reads: 21;
  - the new gateway reads: 40. These cover workspaces, scopes, telemetry, every inventory list
    and its first item, admin guardrails, the report and doctor's `Gateway API` line. Reads whose
    TypeScript output shows a credential run on airs-cli-rs only, and check that it is withheld;
  - the profile transfer flow: 15. It created 5 run-prefixed resources and deleted all 5.
- The live gateway runs found three problems, all fixed before release:
  - the guardrail catalog was over-withheld;
  - JSON cells were compared with key order;
  - workspace `user_api_key_*` settings were withheld.

**Not run live:**
- Gateway writes and inference: writes change shared organisation state, and inference is billed.
  The live tier refuses both.
- `api-keys user get` and `admin-guardrails get`: the tenant has none to read.
- Model security: the tenant still has no access.
