M4t tenant writes: airs-cli-rs now has its own TOML tenant store and manages it with
`tenant create`, `set`, `unset`, `switch`, `delete` and `tenant import`.

## Upgrading from 0.2 (required)

0.3 no longer reads the TypeScript CLI's tenant registry. Copy your tenants once:

```sh
airs-cli-rs tenant import --dry-run   # shows what would be copied; writes nothing
airs-cli-rs tenant import             # copies every tenant and the selection
airs-cli-rs doctor
```

The import reads the TypeScript files without changing them. Until you import, every
command reports that no tenant is registered and points at `tenant import`.

## Changes

- **Tenant store.** `~/.config/airs-cli/` (`$XDG_CONFIG_HOME/airs-cli/`, or
  `AIRS_CLI_CONFIG_DIR`) holds `config.toml` (the selection and each tenant's TSG pin)
  and `tenants/<name>.toml`, with the TypeScript key names. `aiGw*` keys are now
  `gateway*` and `agentGuard*` keys `supplychain*`; `dataDir` and `typesafe*` are gone.
  Files are 0600 and directories 0700. Symlinks, foreign owners and loose modes are
  refused.
- **Safe writes.** Every write takes one `flock` lock (a crashed writer never leaves a
  stale lock; a waiting writer names the holder's pid and host and gives up after 5 s),
  then writes a temp file, fsyncs, renames and fsyncs the directory.
- **`tenant create <name>`** asks for the TSG ID, client ID and secret (hidden), or takes
  `--tsg-id`, `--client-id` and `--client-secret-stdin`. `--config` is gone; use
  `tenant import --from-config <file.json> --name <name>`.
- **`tenant set` / `unset`.** Secrets are never accepted as arguments; omit the value
  for a hidden prompt or use `--stdin`. Values are validated strictly. `set mgmtTsgId`
  updates the TSG pin too.
- **`tenant switch` / `delete`.** `delete` asks for confirmation (`--force` is required
  without a terminal) and removes the tenant's file, so no copy of its secrets is left.
- **`tenant import`.** Copies tenants from the TypeScript registry (`--from`) or one
  JSON config (`--from-config`), with `--name`, `--replace` and `--dry-run`. The report
  lists each tenant's action and notes (renamed, dropped or unknown keys); it never
  prints a value.
- **Doctor** checks the TOML store and, when only a TypeScript registry exists, says to
  run `airs-cli-rs tenant import`.
- **Outcome lines** of the write commands go to stderr and `--quiet` hides them.
