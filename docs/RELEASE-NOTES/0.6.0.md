M6a Red Team: airs-cli-rs now covers every `redteam` command of the TypeScript CLI except
`judge`. That includes scans, targets, adapters, prompt sets, the per-scan and environment
reports, and target backup and restore.

## Install or upgrade

```sh
cargo install --locked airs-cli     # or download a tarball below
airs-cli-rs --version               # 0.6.0
```

No store changes since 0.3; tenants imported with `tenant import` keep working.

## Safety

- **Every write is sent once.** A 401 is retried once with a fresh token. Any other failure
  is never replayed. When the outcome is unknown, the CLI says so and names the read that
  checks it.
- **Confirmations follow the runtime-write rules.** Deletes, aborts, `eula accept` and
  `restore --overwrite` ask on a terminal. Use `--force` to skip the question. Without a
  terminal and without `--force`, the command is refused before the tenant is read.
- **Credentials are redacted** in every output format: auth settings, secret headers,
  `curl` commands, provider keys and `SECRET` variables. Only the credential parts of a
  `curl` command or a URL are withheld. The registry token is printed only with
  `--output json`.
- **`SECRET` adapter variables are refused on the command line.** Pass them in a file with
  `--variables-file`.
- **Files are never overwritten.** This covers `prompt-sets download`, `targets init`, the
  environment report and backups. Each is written exclusively at mode 0600.
- **Scan waits are bounded** by `--wait-timeout`, 24 h by default. Ctrl-C or the bound
  leaves the scan running and names it.
- **Backups** are one airs-cli-rs file per run, holding the tenant, the TSG and the outcome
  of every target. TypeScript backups are refused.
  - A target whose credentials the service masked is stored with
    `"credentialsWithheld": true` and marked ⚠ in the summary. Restore refuses it by name;
    a mask is never sent as a credential.
- **Restore** offers `--dry-run`. It refuses a backup from another TSG unless
  `--allow-other-tenant` is given, and it stops at the first unknown outcome.
- **The environment report** is HTML only, and it is refused under `--debug`.

## Verified

The full loopback and parity suite passes (1952 tests). Against a real tenant:
- The red team reads agreed with the TypeScript CLI on all 19 checks, including the
  environment report and a backup.
- The write flow created, updated and deleted one draft adapter per CLI with equal
  projections and nothing left behind.

The billed scan flow was not run for this release.
