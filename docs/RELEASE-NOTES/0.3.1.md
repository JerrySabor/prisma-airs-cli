Packaging release: the crate is now published on crates.io as `airs-cli`. The commands
are unchanged from 0.3.0.

## Install

```sh
cargo install --locked airs-cli      # installs the airs-cli-rs executable
```

The executable stays `airs-cli-rs` until 1.0, when it becomes `airs-cli` (with an
`airs-cli-rs` symlink). Prebuilt binaries are attached below as before.

Upgrading from 0.2? Run `airs-cli-rs tenant import` once (see the 0.3.0 notes).

## Changes

- The package is renamed from `prisma-airs-cli-rs` to `airs-cli` and published on
  crates.io. The package holds only the sources, `Cargo.lock`, the README and the
  licence.
- `scripts/release.sh` uploads over HTTP/1.1 and retries an upload up to three times
  without ever adding a duplicate asset.

- Three tests that failed intermittently on Linux CI are fixed. The "connection refused" tests now use ports that fixture servers can never be given. `d10` accepts either outcome of TypeScript's jittered retries. A doctor unit test no longer matches digits in its random temporary path.

No new DESIGN §12 rows.
